# Security policy

## Reporting vulnerabilities in this repository

If you find a security issue in **our lab scripts or checker** (not in upstream PHP itself), please open a **private** report via GitHub Security Advisories on [aumlayer/security-labs](https://github.com/aumlayer/security-labs/security/advisories) or contact AUMLayer through your usual channel.

Do **not** use this repo’s issues to coordinate attacks against third parties.

## PHP upstream

Report PHP engine vulnerabilities to the [PHP security team](https://github.com/php/php-src/security/policy) per vendor process.
